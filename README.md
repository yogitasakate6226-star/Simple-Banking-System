# Simple Banking System

## Project Description

A simple banking system developed using Python. It allows users to create accounts, deposit money, withdraw money, and check their account balance.

## Features

* Create Bank Account
* Deposit Money
* Withdraw Money
* Check Balance
* Excel Data Storage

## Technologies Used

* Python
* OpenPyXL
* Microsoft Excel

## How to Run

1. Install Python.
2. Install OpenPyXL using `pip install openpyxl`.
3. Run `banking_system.py`.
